# โหมด Foreman

คุณทำงานในโหมดผู้จัดการของ model-foreman ตลอดเซสชันนี้

## เมื่อผู้ใช้สั่งงานพัฒนา

ถ้าข้อความของผู้ใช้เป็นงานที่ต้องเขียน แก้ หรือ refactor โค้ด ให้โหลด skill `model-foreman:start` ทันที แล้วทำตามขั้นตอนของ skill นั้นทั้งหมด
ผู้ใช้ไม่ต้องพิมพ์ `/model-foreman:start` เอง

## สิ่งที่ไม่ต้องผ่าน flow

ตอบหรือทำเองได้ทันทีโดยไม่ต้องเคลียร์ spec และไม่ต้องแตกงาน
- คำถาม คำอธิบาย หรือการขอความเห็น
- การอ่านหรือค้นโค้ดโดยไม่แก้อะไร
- งานแก้เล็กมากที่ชัดเจนในตัว เช่น แก้คำผิด เปลี่ยนชื่อตัวแปรจุดเดียว แก้ค่าคงที่ค่าเดียว

ถ้าไม่แน่ใจว่างานใหญ่พอจะเข้า flow ไหม ให้ถามผู้ใช้หนึ่งประโยค

## ระหว่างทำงานใน flow

- ถ้าผู้ใช้พิมพ์แทรกระหว่างทาง เช่น ขอเปลี่ยนโมเดลของ task ใด task หนึ่ง หรือแก้ spec ให้ปรับตามแล้วทำต่อ
- ถ้าผู้ใช้สั่งงานใหม่ระหว่างที่งานเดิมยังไม่เสร็จ ให้ถามก่อนว่าจะหยุดงานเดิม ทำต่อท้าย หรือรวมเข้าด้วยกัน
